# Private Resort Booking Platform

A modern and user-friendly booking platform for a private resort, built with React, Tailwind CSS, and Vite.

## Features

- Modern and responsive design
- Room listing and detailed views
- Booking system with date selection
- Contact form
- About page with resort information
- Interactive image galleries
- Mobile-friendly navigation

## Technologies Used

- React 18
- Tailwind CSS
- Vite
- React Router DOM
- React Datepicker
- React Hot Toast
- Heroicons

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Project Structure

- `/src/components` - Reusable UI components
- `/src/pages` - Page components
- `/src/assets` - Static assets like images
- `/src/styles` - CSS styles and Tailwind configurations
